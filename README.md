Google Photos Extractor
A tool for automatically extracting and organizing Google Photos archives, with metadata support and HEIC conversion.
Features
  File Management: Structured data extraction, format conversion, and duplicate protection via MD5 hashing.
  Performance: Multithreaded processing to speed up work with large archives.
  Interface: Runs in the system tray with drag-and-drop support.
  Reliability: Error logging, free space checking, and saving settings to AppData.
Technical Features

  Optimization: Secure management of descriptors and threads for stability in the Windows environment.
  Architecture: Use of modern libraries for GUI and system integration.

Development
The project was designed using artificial intelligence (Gemini) to achieve optimal architecture, clean code, and stable task execution.
Usage
1. Run the executable file.
2. Select or drag and drop archives into the program window.
3. Configure the settings and start the process.
