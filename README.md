Google Photos Extractor

A tool for automatically extracting and organizing Google Photos archives.

Key Features

Flexible Structure: Preserve original folders, create a single archive, or rename all files by capture date.
Metadata Handling: Automatically reads JSON data to determine the actual creation date of photos and videos.
Smart Cleanup: Removes duplicates by comparing MD5 hashes.
Conversion: Automatically convert HEIC and HEIF formats to standard JPEG.
Resource management: Multithreaded processing with selectable number of cores and disk space check.
Integration: Runs in the system tray and supports drag-and-drop.

Supported formats

Archives: .zip
Images: .jpg, .jpeg, .png, .heic, .heif, .webp
Video: .mp4, .mov, .avi, .mkv
Metadata: .json

Instructions

1. Launch: Open the program’s executable file.
2. Selecting files: Drag ZIP archives containing photos directly into the program window or click the “Browse” button.
3. Settings: Select the number of CPU cores to use, the desired file sorting method, and additional options such as HEIC conversion.
4. Processing: Click the “START” button. The program will display the progress bar and automatically offer to open the results folder upon completion.
5. Troubleshooting: If errors occur, click the “Open Error Log” button to view details.

   Google Photos Extractor

Инструмент для автоматической распаковки и упорядочивания архивов Google Фото.

Главные функции

Гибкая структура: Сохранение оригинальных папок, создание общего архива или переименование всех файлов по дате съемки.
Работа с метаданными: Автоматическое чтение JSON-данных для установки реальной даты создания фото и видео.
Умная очистка: Удаление дубликатов с помощью сравнения MD5-хэшей.
Конвертация: Автоматическое преобразование форматов HEIC и HEIF в стандартный JPEG.
Управление ресурсами: Многопоточная обработка с выбором количества ядер и проверка свободного места на диске.
Интеграция: Работа в системном трее и поддержка перетаскивания файлов (Drag-and-Drop).

Поддерживаемые форматы

Архивы: .zip
Изображения: .jpg, .jpeg, .png, .heic, .heif, .webp
Видео: .mp4, .mov, .avi, .mkv
Метаданные: .json

Инструкция по работе

1. Запуск: Откройте исполняемый файл программы.
2. Выбор файлов: Перетащите ZIP-архивы с фотографиями прямо в окно программы или нажмите кнопку «Обзор».
3. Настройка: Выберите количество используемых ядер процессора, желаемый способ сортировки файлов и дополнительные параметры, такие как конвертация HEIC.
4. Обработка: Нажмите кнопку «СТАРТ». Программа отобразит прогресс выполнения и автоматически предложит открыть папку с результатами по завершении.
5. Контроль: В случае ошибок нажмите кнопку «Открыть лог ошибок», чтобы просмотреть детали.
